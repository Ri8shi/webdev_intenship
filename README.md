## About

This repository collects materials for a web development internship: tutorials, coding challenges, starter templates (HTML/CSS/JS and Node/Express), and example projects.

It's intended to be a central place for interns to clone, complete exercises, open pull requests with solutions, and track progress.

## What's included

- Starter frontend projects (HTML, CSS, JavaScript)
- Backend examples (Node.js + Express)
- Small full-stack exercises connecting frontend to backend APIs
- Notes, reading lists, and useful links

## Prerequisites

- Git (latest stable)
- Node.js LTS (v16+ or v18+ recommended)
- npm or yarn
- A modern web browser (Chrome/Firefox/Edge)

## Getting started (local)

1. Clone the repository

   git clone https://github.com/Ri8shi/webdev_intenship.git
   cd webdev_intenship

2. Open a starter project or exercise folder (e.g., `starter/frontend` or `exercises/todo-app`)

3. Install dependencies for Node-based projects

   npm install

4. Run the development server (if provided)

   npm run dev

5. Open the app in your browser (commonly http://localhost:3000)

## Development workflow

- Create a new branch for your changes: `git checkout -b feat/my-solution`
- Commit early, commit often, and write clear commit messages
- Push your branch and open a Pull Request (PR) to the `main` branch
- Peer reviews or mentor reviews will provide feedback before merging
